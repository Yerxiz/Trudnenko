# Shell Emulator

Эмулятор командной оболочки UNIX-подобной ОС.

## Этап 1. REPL

Минимальный прототип: интерактивный диалог с пользователем, парсер

аргументов, команды-заглушки.

### Возможности

- Приглашение формируется из реальных данных ОС: `user@host:cwd$`

- Парсер с поддержкой одинарных и двойных кавычек

- Команды-заглушки: `ls`, `cd`

- Команда `exit`, а также обработка Ctrl-D и Ctrl-C

- Обработка ошибок: неизвестная команда, незакрытая кавычка

### Запуск

```bash
python3 src/terminal.py
```

## Этап 2. Конфигурация

Эмулятор поддерживает параметры командной строки:

| Параметр          | Обязательный | Описание                              |
|-------------------|--------------|---------------------------------------|
| `--vfs <path>`    | да           | Путь к физическому расположению VFS   |
| `--script <path>` | нет          | Путь к стартовому скрипту с командами |

При запуске печатается отладочный вывод всех заданных параметров.

### Запуск

```bash
python3 src/terminal.py --vfs ./vfs
python3 src/terminal.py --vfs ./vfs --script scripts/startup_demo.txt
```

## Этап 3. VFS

Виртуальная файловая система полностью загружается в память из
JSON-файла. Все операции (ls, cd, cat, tree) выполняются над
in-memory структурой, диск не модифицируется.

### Параметры командной строки

| Параметр          | Обязательный | Описание                              |
|-------------------|--------------|---------------------------------------|
| `--vfs <path>`    | да           | Путь к **JSON-файлу** с описанием VFS |
| `--script <path>` | нет          | Путь к стартовому скрипту с командами |

### Формат VFS

```json
{
  "type": "directory",
  "children": {
    "etc": {
      "type": "directory",
      "children": {
        "hosts": {
          "type": "file",
          "content": "127.0.0.1 localhost\n"
        }
      }
    },
    "bin": {
      "type": "directory",
      "children": {
        "data.bin": {
          "type": "file",
          "encoding": "base64",
          "content": "SGVsbG8sIGJpbmFyeSB3b3JsZCEK"
        }
      }
    }
  }
}
```

## Этап 4. Основные команды

Поддерживаемые команды:

| Команда   | Синтаксис                    | Описание                                                              |
|-----------|------------------------------|-----------------------------------------------------------------------|
| `ls`      | `ls [-l] [path...]`          | Список содержимого директории. `-l` — подробный формат (тип, размер). |
| `cd`      | `cd [path]`                  | Смена текущей директории. Без аргумента — переход в `/`.              |
| `pwd`     | `pwd`                        | Печать текущей директории.                                            |
| `cat`     | `cat file...`                | Вывод содержимого файла.                                              |
| `tree`    | `tree [path]`                | Дерево директорий.                                                    |
| `history` | `history [N]` / `history -c` | История команд. `N` — последние N, `-c` — очистить.                   |
| `head`    | `head [-n N] file...`        | Первые N строк файла (по умолчанию 10).                               |
| `rev`     | `rev file...`                | Переворот символов в каждой строке файла.                             |
| `exit`    | `exit`                       | Выход.                                                                |

### Тестовый скрипт

`scripts/startup_stage4.txt` покрывает все режимы каждой команды
и примеры ошибок (несуществующий путь, файл вместо директории,
некорректные опции).

## Этап 5. Дополнительные команды

| Команда | Синтаксис                | Описание                                    |
|---------|--------------------------|---------------------------------------------|
| `cp`    | `cp [-r] source... dest` | Копирование файлов и директорий внутри VFS. |

### Режимы `cp`

- `cp file1 file2` — копия `file1` с именем `file2`.
- `cp file /existing_dir` — копия в директорию с сохранением имени.
- `cp f1 f2 /existing_dir` — несколько источников копируются в директорию.
- `cp -r dir1 dir2` — рекурсивное копирование директории.

### Отличия от системного `cp`

- Все изменения — **только в памяти**. Файл VFS на диске не перезаписывается
  и не изменяется. После завершения эмулятора VFS возвращается к исходному
  состоянию из JSON.
- Копирование **не перезаписывает** существующий узел назначения —
  операция завершается ошибкой `cannot overwrite`.
- Копирование директории в себя (`cp -r /etc /etc`) запрещено.

### Тестовый скрипт

`scripts/startup_stage5.txt` покрывает все режимы `cp` и все
ошибочные сценарии (нет аргументов, нет источника, нет родительской
директории, копирование в себя, отсутствие `-r`, неизвестная опция,
попытка перезаписи).
