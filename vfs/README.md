# VFS test fixtures

| Файл | Назначение |
|---|---|
| `minimal.json` | один файл в корне |
| `basic.json`   | несколько файлов и папок |
| `deep.json`    | минимум 3 уровня вложенности |
| `binary.json`  | файл с base64-содержимым |
| `invalid.json` | специально сломанный JSON для проверки ошибок |

Файл `no_such.json` намеренно не создаётся — используется для теста
«VFS не найден».
